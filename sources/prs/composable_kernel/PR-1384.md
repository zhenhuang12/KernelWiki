## Summary

Adds a performance-tuned plain FP8 GEMM instance to Composable Kernel for CDNA 3 (gfx942). The kernel feeds `v_mfma_f32_*_fp8_fp8` from LDS-staged A/B tiles and pairs heuristic-selected tile / block / wave sizes with the existing CK GEMM pipeline.

## Why It Matters

This is the canonical FP8 GEMM entry point in CK before the wave-specialized BlockGemmPipelineV3/V4 family landed. Downstream MFMA FP8 GEMM PRs (V2, ping-pong V3, MX variants) all build on the tile shapes, LDS layout, and config-selection logic introduced here.
