## Summary

Introduces `GemmPipelineAGmemBGmemCRegV2` ("Compute V2") in ck_tile, which uses two LDS buffers in a ping-pong arrangement: one buffer is consumed by MFMA while the other is filled by `buffer_load_dword_lds`. The scheduling mirrors the older CK `BlockGemmPipelineV4` but is rewritten in the ck_tile tile-programming style.

## Why It Matters

For large M·N tile shapes on CDNA 3 / CDNA 4, the 2-LDS ping-pong scheme is the recommended pipeline because it hides global-load latency while keeping the MFMA stream saturated. This PR becomes the reference for subsequent ck_tile GEMM variants (FP8, MX-scaled) that need wave-specialized producer/consumer behavior.
