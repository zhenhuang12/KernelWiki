## Summary

Adds the `fmha_fwd_v3` pipeline to ck_tile — CK's port of the FlashAttention-3-style forward algorithm with producer/consumer wave specialization for QK matmul, softmax, and PV matmul stages. Initial enablement targets gfx950 (CDNA 4).

## Why It Matters

This is the canonical CK reference for the FAv3 algorithm on AMD: it shows how to express the FA3 producer/consumer split using ck_tile wave specialization, `buffer_load_dword_lds` for tile prefetch, and the CDNA 4 MFMA shapes. Subsequent AITER FP8 FMHA ASM kernels build on the algorithmic skeleton introduced here.
