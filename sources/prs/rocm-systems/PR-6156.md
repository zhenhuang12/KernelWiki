## Summary

Realigns RCCL's Direct AllGather path with the AlltoAll implementation in the rocm-systems monorepo (where active RCCL development now lives). Removes the previous 32-node guard and fixes a hang at >32 nodes when P2P batching is enabled.

## Why It Matters

AllGather is on the hot path for tensor-parallel and EP-prefill workflows; the 32-node guard had blocked larger MI300X / MI355X clusters from using the Direct path. This PR is the canonical reference for the post-monorepo RCCL collective code (ROCm/rccl now only receives backport cherry-picks for stable branches).
