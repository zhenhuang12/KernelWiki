## Summary

Adds the first FP8 FMHA ASM kernel for gfx950 (CDNA 4) at head-dim 128, adapted from the existing MLA hd=192 ASM kernel. Uses `v_mfma_f32_*_fp8_fp8`, AGPR-resident accumulators, and LDS-staged Q/K/V tiles, hand-scheduled in AMDGCN assembly.

## Why It Matters

Reports ~25% end-to-end speedup over the BF16 FMHA path on diffusion workloads (xDiT video generation). For kernel authors this is the reference for porting an existing MLA-style ASM skeleton to a different head-dim and dtype combination on CDNA 4.
